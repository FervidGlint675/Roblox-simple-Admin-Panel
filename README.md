# Roblox-simple-Admin-Panel
This is a simple Admin Panel on roblox studio that is capble of doing function as the Ban,Tp,Kick in a ScreenGui and Unban (by the chat :unban Player1)  Create these in ReplicatedStorage: - RemoteEvent: KickPanel - RemoteEvent: BanPanel   - RemoteEvent: TpPanel - RemoteFunction: IsAdmin  Then add your UserId to the Admins table in the ServerScript.
